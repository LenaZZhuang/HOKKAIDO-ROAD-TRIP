      ONLINE TAX REFUND

      線上退稅教學

      出境時用手機在 Visit Japan Web 完成退稅手續，不用排退稅機台。以下 7 個機場的國際線出發樓層可以辦理，我們回程的新千歲機場也在內。

      新千歲成田羽田中部關西福岡那霸
      BEFORE YOU GO

      出發前先在 Visit Japan Web 準備好

      • 登錄「護照的臉部照片」
      • 登錄「入境許可證明資訊」
      • 免稅購物結帳時，出示 Visit Japan Web 的「免稅 QR 碼」
      1. 1STEP

        登入 Visit Japan Web

        登入後，在「入境後使用」點「免稅購買・退稅手續」，進入免稅頁面。

      2. 2STEP

        連上機場退稅專用 Wi-Fi

        到國際線出發樓層後，掃 QR Code 或手動輸入，連上海關的退稅專用 Wi-Fi。

        SSID
        Customs_WiFi_For_TaxRefund
        PW
        jcustoms
      3. 3STEP

        選取「退稅手續」

        回到 Visit Japan Web 的「免稅購買・退稅手續」頁面，在「離境時」點「退稅手續」。

      4. 4STEP

        確認購買紀錄，按「Confirm」

        核對畫面上的免稅購買紀錄（店名、日期、金額）都正確後，點綠色的「Confirm」按鈕。

      5. 5STEP

        確認手續結果

        Completed手續完成。退款依各免稅店的指示辦理。
        Not Completed請到出發大廳的海關窗口，依海關人員要求出示商品。

      流程與畫面取自日本國稅廳「線上退稅手續」說明，詳細內容以官方頁面為準：國稅廳 線上退稅手續（繁體中文）↗
